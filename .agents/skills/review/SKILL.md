# Project Review

1. `/AGENTS.md`, `/docs/ARCHITECTURE.md`, `/docs/ADR.md`를 읽는다.
2. 변경된 파일을 확인한다.
3. 다음 항목을 검증한다.
   - ARCHITECTURE.md의 디렉터리 구조 준수
   - ADR의 기술 선택 준수
   - 새 기능에 대한 테스트 존재
   - AGENTS.md의 CRITICAL 규칙 준수
   - 빌드 명령 성공
4. 다음 표로 결과를 보고한다.

| 항목 | 결과 | 비고 |
|---|---|---|
| 아키텍처 준수 | ✅/❌ | 상세 |
| 기술 스택 준수 | ✅/❌ | 상세 |
| 테스트 존재 | ✅/❌ | 상세 |
| CRITICAL 규칙 | ✅/❌ | 상세 |
| 빌드 가능 | ✅/❌ | 상세 |

위반 사항이 있으면 파일과 위치를 명시하고 구체적인 수정 방안을 제시한다.
